Tote Inventory

Track totes owned and estimate how many are out on rental right now — including confirmed bookings that haven't been invoiced yet — and project availability forward using every rental on the books. Uses the Tote/Dolly count set on each rental; older rentals without one fall back to parsing the package name.

Confirmed, Not Yet Invoiced

Bookings marked Confirmed on the Requests page don't count anywhere else until they're actually invoiced — this is the gap that caused the count to drift before. Totes here are estimated from the package name, since requests don't have a set tote count the way rentals do.

Data cleanup

Sets Tote/Dolly counts on older rentals from before those fields existed, by parsing the package text. Skips anything it can't confidently parse (e.g. "Custom Package") so it never guesses a wrong number — you'll get a list to fix by hand.

Inventory Calendar (Past 60 Days → Next 60 Days)

Plenty free Under 20 free Zero or oversold Today

Each cell is totes owned minus everything scheduled to be out that day. Past days are reconstructed from your logged rentals and stock events, so this is only as accurate as what's been logged. Future days project forward using every rental on the books (not just currently active ones) and your current tote count, so you can see upcoming crunches before they happen.
